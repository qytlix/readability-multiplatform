# 标签系统 — 用户交互流程

## Phase 1 — 手动标签

### 给文章加标签

```
1. 打开任意一篇文章（EntryDetail 阅读页）
       │
2. 在文章工具栏看到新的 🏷️ 标签按钮
       │
3. 点击 🏷️ → 弹出 TagFloatingWindow
       │
       ├── 浮窗中显示该文章已有标签（首次打开为空）
       │
       ├── 在输入框输入标签名，按回车
       │      │
       │      ├── 标签名 ≤ 50 字符 → 创建成功
       │      │    标签以 pill 形式出现在浮窗中
       │      │    标签自动获得颜色（基于标签名的哈希值）
       │      │    标签持久化到数据库
       │      │
       │      └── 标签名空字符串 → 无反应，可继续输入
       │
       └── 点击标签 pill 上的 × 按钮
              │
              └── 标签从该文章移除
                    浮窗中消失
                    数据库 entry_tag 记录删除（tag 表仍保留）
```

### 关闭/重开

```
4. 点击浮窗外区域 或 按 Escape → 浮窗关闭
       │
5. 切换到其他文章再切回来 → 再次打开 🏷️
       │
       └── 浮窗显示该文章已保存的标签，与关闭前一致
```

## Phase 2 — AI 标签

### 前置条件

```
用户在 Settings → AI 页面中配置了 AI Provider（复用 Summary 同款配置）
Tag Agent 默认配置：手动触发 + 手动确认
```

### Settings → AI 中看到新的 Tag Agent 配置区

```
┌────────────────────────────────────────┐
│  Tag Agent                             │
│                                         │
│  触发方式    [● 手动触发] [○ 自动触发]  │
│  确认方式    [● 手动确认] [○ 自动确认]  │
│  最大候选数  [  8        ]              │
└────────────────────────────────────────┘
```

修改后即时生效，无需保存按钮。

### 手动触发 + 手动确认（默认）

```
1. 打开一篇文章 → 点击 🏷️ → 打开 TagFloatingWindow
       │
2. 浮窗中新增「AI 标签」区域
       │
3. 点击 [✨ 生成标签] 按钮
       │
       ├── 按钮显示 loading 动画，文字变为「正在生成...」
       │    后端调用 AI Provider 分析文章内容
       │
       ├── 成功 → 候选标签列表以 checkbox 形式展示
       │    ☑ AI       ☑ 机器学习  ☐ 深度学习
       │    每个候选标签自带自动生成的颜色
       │
       ├── 勾选需要的标签（可全选或部分）
       │
       ├── 点击 [确认添加]
       │      │
       │      ├── 未勾选任何标签 → 按钮灰色不可点击
       │      ├── 已勾选 → 标签落库（source = 'auto'）
       │      │    浮窗「当前标签」区域刷新
       │      │    AI 标签以虚线边框区分于手动标签
       │      │    浮窗不关闭，可继续手动添加
       │      │
       │      └── 确认后候选列表清空，按钮恢复 [✨ 生成标签]
       │
       └── 失败（Provider 未配置/网络错误）
             按钮恢复，显示红色提示「标签生成失败，请检查 AI 配置」
```

### 手动触发 + 自动确认

```
1. 用户在 Settings 中将确认方式改为「自动确认」
       │
2. 打开文章 → 点击 [✨ 生成标签] → loading
       │
3. AI 返回后直接落库，不展示候选列表
       │
       └── toast 提示「已为本文添加 N 个标签」
           浮窗自动刷新标签列表
```

### 自动触发 + 自动确认

```
1. 用户在 Settings 中将触发方式改为「自动触发」
       │
2. 打开一篇文章
       │
       ├── 文章已有标签 → 不做任何事
       │
       └── 文章无标签且已清洗 → 静默调用 AI
              ├── AI 返回 → 直接落库
              │    toast 提示「已为本文添加 N 个标签」
              │
              └── 用户可随时打开 🏷️ 查看已自动添加的标签
```

### 自动触发 + 手动确认

```
1. 打开一篇无标签文章
       │
2. 自动触发 AI 请求
       │
       └── 候选标签返回 → TagFloatingWindow 自动打开
            展示候选列表供用户勾选
            浮窗不自动关闭，等待用户操作
```

## Phase 3 — 标签列表页 + 筛选

### 标签导航入口

```
1. 侧边栏导航新增「🏷️ 标签」条目
       │
       └── 位于「所有文章」「收藏」「未读」之后
```

### 查看全部标签

```
1. 点击「🏷️ 标签」→ 主区域切换为标签列表页
       │
       ├── 展示所有标签（按文章数降序）
       │    [AI]              12 篇文章
       │    [机器学习]         8 篇文章
       │    [深度学习]         5 篇文章
       │    ...
       │
       ├── 每个标签显示自动生成的颜色 pill + 文章数
       │
       └── 没有任何标签时 → 显示「暂无标签」
```

### 按标签筛选文章

```
1. 在标签列表页点击某个标签
       │
       ├── 跳转到文章列表（EntryList 视图）
       │    列表仅显示包含该标签的文章
       │    页面顶部显示「标签：AI」的筛选指示
       │
       ├── 每篇文章条目下方显示其标签 pill
       │    [AI] [ML]
       │
       └── 页面侧边栏/顶部可切换标签或取消筛选
```

### 标签筛选 × 搜索

```
1. 在标签筛选状态下，搜索框正常可用
       │
2. 输入关键词 → 结果同时满足标签和搜索条件
       │
3. 清除搜索词 → 回到纯标签筛选结果
       │
4. 取消标签筛选 → 搜索词保留，结果变为纯搜索
```

### 标签筛选取消

```
1. 在标签筛选状态下 → 点击筛选指示上的 × 或再次点击同一标签
       │
       └── 筛选取消，恢复全部文章
```
