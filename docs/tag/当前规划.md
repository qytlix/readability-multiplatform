## Overall Goal

为文章提供多对多标签系统，支持手动打标签、AI 自动生成标签、标签列表页与标签筛选，覆盖从数据模型到 UI 的完整链路。

## Task Detail

### 范围

#### 包含
- 文章 ↔ 标签多对多关系（`tag` + `entry_tag` 表）
- 手动添加/删除标签（浮动窗口 UI）
- AI 标签生成（复用已配置的 LLM Provider）
- Tag Agent 配置项（触发模式 + 确认模式）
- 标签列表页（与「所有文章」「收藏」「未读」同级导航）
- 文章列表显示标签 pill
- 按标签筛选文章
- 标签 × 搜索协同过滤
- 标签颜色自动生成（哈希 → HSL 色相环）

#### TODO
- 多选模式批量操作
- 标签导入/导出
- 标签合并/重命名
