| # | 验收项 | 操作 | 预期 | 状态 |

## 人工验证检查表

```bash
npm start
# ── 单篇导出 ──
# 1. 打开已清洗文章 → 点击导出 → 勾选总结 → 下一步 → 保存 → 验证文件
# 2. 打开已清洗文章 → 不勾选翻译 → 下一步 → 保存 → 验证无翻译块
# 3. 打开未清洗文章 → 导出按钮 disabled
# 4. 导出 → 取消 → 无空文件

# ── 多篇导出 ──
# 5. 点击「选择」→ 勾选 2 篇 → 点击导出 → 选项对话框显示 2 篇
# 6. 全选总结 → 取消全选总结 → 正常
# 7. 未清洗文章 → 点击「现在清洗」→ 清洗完成 → checkbox 可用
# 8. 清洗全部 → 全部完成 → 下一步可用
# 9. 保存 → 文件包含 2 篇文章 → 自动退出多选
# 10. 导出 → 取消 → 回到多选，选中保持
```
