# 导出功能交互设计

> 最终确认的交互流程
> 记录日期：2026-07-26

---

## 1. 单篇导出

**前提：** 当前阅读文章已清洗完成（未清洗时导出按钮 disabled，tooltip 提示"文章尚未完成内容清洗"）

### 流程

```
步骤1 — 点击导出按钮

  AI 工具栏中找到 ⬇️ 导出按钮（在「字体」与「...更多」之间）
  tooltip: "导出为 Markdown"
  → 点击按钮

步骤2 — 选项对话框

  ┌──────────────────────────────────────────────┐
  │  📄 导出文件                                 │
  │                                              │
  │  标题：当前文章标题                           │
  │                                              │
  │  ☑ 包含总结     ☑ 包含翻译     ☐ 包含笔记     │
  │  (灰显不可用)   (灰显不可用)   (灰显不可用)    │
  │                                              │
  │              [  取消  ] [  下一步  ]          │
  └──────────────────────────────────────────────┘

  - 标题显示当前文章
  - 三个 checkbox：根据文章实际数据决定可用性
    - 有数据 → 可勾选，默认 ✅
    - 无数据 → 保持灰显且不能改变选中状态；点击或键盘操作时，页面右下角提示该文章暂无对应内容
  - 点击「取消」→ 关闭对话框，不退出当前阅读
  - 点击「下一步」→ 进入系统保存对话框

步骤3 — 系统保存对话框

  Electron 原生对话框
  默认路径：文档目录 / 安全文件名（所选附加内容）.md
  示例：文章标题（翻译、总结）.md
  文件类型：Markdown（*.md）

  行为：
  - 选择保存位置 → 写入 .md → ✅ 完成
  - 点击取消 → 无空文件，返回阅读
```

## 2. 多篇导出

### 2.1 进入多选模式

```
文章列表头部有 ☑️「选择」按钮（与 🔽 Filter 并列）

普通模式：显示 ☑️「选择」
多选模式：显示 ☑️「选择」（高亮 .is-active）

点击 toggle 切换入口/出口
```

### 2.2 多选模式下的界面

```
文章列表：
  ┌─────────────────────────────────┐
  │  ☑️ 选择（高亮）                 │
  │  已选 3 篇                       │
  ├─────────────────────────────────┤
  │  ☑ 文章 A                       │
  │  ☐ 文章 B                       │
  │  ☑ 文章 C                       │
  │  ☑ 文章 D                       │
  │  ☐ 文章 E                       │
  │  ...                            │
  └─────────────────────────────────┘

  - 每张文章卡片左侧出现 checkbox
  - 顶部显示「已选 N 篇」（仅计数，无操作按钮）
  - 点击卡片 → 切换勾选，不导航到阅读器
```

### 2.3 完整流程

```
步骤1 — 进入多选模式

  点击 ☑️「选择」按钮
  → 按钮高亮，进入多选模式

步骤2 — 勾选文章

  逐篇点击卡片勾选
  顶部实时更新「已选 N 篇」
  可翻页，选中保持
  切换 Filter → 自动退出多选，清空选中

步骤3 — 点击导出

  AI 工具栏的 ⬇️ 按钮 tooltip 变为：「导出所选 N 篇文章」
  → 点击按钮

步骤4 — 选项对话框

  ┌──────────────────────────────────────────────────────┐
  │  📄 导出文件                                         │
  │                                                      │
  │  [全选总结]   [全选翻译]   [全选笔记]   ← 列级按钮   │
  │  ─────────────────────────────                       │
  │  ✅ 文章 A        ☑ 总结  ☑ 翻译  ☐ 笔记             │
  │  ⏳ 文章 B        🧹未清洗  [现在清洗]                │
  │  ✅ 文章 C        ☑ 总结  ☐ 翻译  ☑ 笔记             │
  │  ⏳ 文章 D        🧹未清洗  [现在清洗]                │
  │  ─────────────────────────────                       │
  │  [🧹 清洗全部未清洗（2篇）]                           │
  │                    [  取消  ] [  下一步  ]            │
  └──────────────────────────────────────────────────────┘

  每篇文章一行：
    ✅ 已清洗 → 三个 checkbox 可按数据情况勾选
    ⏳ 未清洗 → 显示「🧹 现在清洗」按钮，不显示 checkbox
    ❌ 清洗失败 → 显示「❌ 清洗失败」，该行不可导出

  列级按钮：
    「全选总结」→ 所有已清洗文章的「总结」全勾上，变为「全不选」
    「全选翻译」→ 同上
    「全选笔记」→ 同上

  底部「清洗全部未清洗（N 篇）」：
    → 逐篇清洗所有未清洗文章

  按钮状态规则：
    「下一步」：
      - 没有任何已清洗可勾选的文章 → disabled
      - 正在清洗 → disabled
      - 否则 → 可点击
    「取消」：
      - 始终可点击
      - 点击 → 关闭对话框，回到多选模式，选中的文章保持选中

步骤4a — 清洗中子流程

  触发清洗的方式（二选一）：
    a. 点击某篇的「现在清洗」→ 单独清洗该篇
    b. 点击「清洗全部未清洗」→ 批量清洗

  清洗中的界面变化：
    - 该行显示「🔄 清洗中...」
    - 「下一步」disabled
    - 「取消」仍然可点击

  清洗完成：
    - 该行变为 ✅，出现可勾选的 checkbox
    - 如果还有未清洗的 → 继续显示「现在清洗」按钮
    - 全部清洗完成 → 「下一步」恢复可用

  用户点击「取消」：
    - 已清洗完成的文章保持清洗结果
    - 未开始/进行中的清洗停止
    - 对话框关闭，回到多选模式，选中的文章保持选中

步骤5 — 系统保存对话框

  Electron 原生对话框
  默认文件名：「文摘-2026-07-26（翻译、总结、笔记）.md」
  后缀取所有文章实际勾选项的并集；未勾选附加内容时不添加后缀
  文件类型：Markdown（*.md）

  行为：
  - 选择保存位置 → 写入 .md → 自动退出多选模式，清空选中
  - 点击取消 → 无空文件，回到多选模式，选中的文章保持选中
```

## 3. 退出多选的方式汇总

| 触发方式 | 清空选中？ | 备注 |
|---------|-----------|------|
| 再次点击 ☑️「选择」toggle 按钮 | ✅ 清空 | 手动退出 |
| 切换 Filter（全部/未读/收藏） | ✅ 清空 | 列表内容变了 |
| 导出「下一步」后保存成功 | ✅ 清空 | 导出完成自动退出，并在页面右下角提示 Markdown 文档已成功导出 |
| 导出选项对话框点击「取消」 | ❌ **不清空** | 回到多选可继续操作 |
| 系统保存对话框点击取消 | ❌ **不清空** | 回到多选可继续操作 |
| 翻页/加载更多 | ❌ 不清空 | 跨页选择 |

## 4. 按钮 disabled 规则

| 场景 | 导出按钮 | 选项对话框「下一步」 | 选项对话框「取消」 |
|------|---------|-------------------|-----------------|
| 普通模式 — 文章未清洗 | disabled | — | — |
| 普通模式 — 已清洗 | 可点击 | 可点击 | 可点击 |
| 多选模式 — 无选中 | 可点击（点开对话框后无文章可选 → 下一步 disabled） | disabled | 可点击 |
| 多选模式 — 有选中，全部已清洗 | 可点击 | 可点击 | 可点击 |
| 多选模式 — 有选中，部分未清洗 | 可点击 | disabled（除非跳过） | 可点击 |
| 多选模式 — 正在清洗 | 可点击（但对话框已打开） | disabled | **可点击** |
| 多选模式 — 全部清洗完成 | 可点击 | 可点击 | 可点击 |

---

## 5. 每篇文章的选项独立性

- 每篇文章的 checkbox 状态**相互独立**
- 列级「全选」只影响**该列、已清洗**的文章
- 某文章没有某类数据 → 对应 checkbox 灰显且不可改变；用户尝试选择时显示右下角原因提示
- 导出时每篇文章按各自的选项决定是否包含总结/翻译/笔记
